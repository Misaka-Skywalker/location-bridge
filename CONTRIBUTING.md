# Contributing / 参与贡献

Issues and pull requests are welcome. Describe the problem and the intended behavior, include a minimal reproduction, and distinguish device observations from assumptions. Run `python3 scripts/run_tests.py` before submitting changes; for device-dependent changes, state the hardware and OS versions in general terms and what was actually tested. Do not include credentials, pairing records, signing keys, device identifiers, real coordinates, screenshots or private logs.
